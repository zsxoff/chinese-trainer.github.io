## Опорные слова

| Иероглифы | Пиньинь  | Перевод                  |
| --------- | -------- | ------------------------ |
| 次        | cì       | раз, повторение действия |
| 两        | liǎng    | два перед счётным словом |
| 三        | sān      | три                      |
| 去        | qù       | ходить, ездить           |
| 看        | kàn      | смотреть, читать         |
| 找        | zhǎo     | искать                   |
| 中国      | Zhōngguó | Китай                    |
| 书        | shū      | книга                    |

## Главная идея

**次** считает повторения действия. Конструкция **число + 次** отвечает на вопрос «Сколько раз?».

Для «два раза» используй **两次**, а не **二次**.

## Основной порядок слов

Если у глагола есть дополнение, используй схему **глагол + дополнение + число + 次**.

| Иероглифы          | Пиньинь                          | Перевод                     |
| ------------------ | -------------------------------- | --------------------------- |
| 我看过这本书两次。 | Wǒ kàn guo zhè běn shū liǎng cì. | Я читал эту книгу два раза. |
| 我去过中国三次。   | Wǒ qù guo Zhōngguó sān cì.       | Я был в Китае три раза.     |

**过** после глагола показывает, что такой опыт был в прошлом. Количество повторений выражает конструкция **число + 次**.

## Если дополнение — личное местоимение

Сначала поставь местоимение, затем **число + 次**.

> 我找过他三次。
> Wǒ zhǎo guo tā sān cì.
> Я искал его три раза.

## Если дополнение — название места

Название места можно поставить как перед **число + 次**, так и после этой конструкции.

| Иероглифы        | Пиньинь                    | Перевод                 |
| ---------------- | -------------------------- | ----------------------- |
| 我去过中国三次。 | Wǒ qù guo Zhōngguó sān cì. | Я был в Китае три раза. |
| 我去过三次中国。 | Wǒ qù guo sān cì Zhōngguó. | Я был в Китае три раза. |

Запомни: **число + 次** сообщает, сколько раз произошло действие; личное местоимение ставится перед этой конструкцией.
