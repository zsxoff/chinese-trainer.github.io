## Опорные слова

| Иероглиф | Пиньинь | Перевод             |
| -------- | ------- | ------------------- |
| 零       | líng    | ноль                |
| 度       | dù      | градус              |
| 以下     | yǐ xià  | ниже                |
| 气温     | qì wēn  | температура воздуха |
| 在       | zài     | находиться          |

## Как назвать температуру

Используй схему **число + 度**.

| Иероглифы  | Пиньинь           | Перевод                |
| ---------- | ----------------- | ---------------------- |
| 今天五度。 | Jīn tiān wǔ dù.   | Сегодня пять градусов. |
| 今天零度。 | Jīn tiān líng dù. | Сегодня ноль градусов. |

## Как сказать «ниже нуля»

Если точное значение неважно, используй **零度以下** — «ниже нуля градусов».

> 气温在零度以下。
> Qì wēn zài líng dù yǐ xià.
> Температура воздуха ниже нуля.

Здесь **在** связывает температуру воздуха с состоянием «ниже нуля».

## Как назвать отрицательную температуру

Для конкретного значения используй схему **零下 + число + 度**.

> 今天零下五度。
> Jīn tiān líng xià wǔ dù.
> Сегодня минус пять градусов.

**零下** ставится перед числом и показывает, что температура ниже нуля.

## Не перепутай конструкции

| Что нужно сказать                                 | Конструкция       | Пример           |
| ------------------------------------------------- | ----------------- | ---------------- |
| Температура ниже нуля, точное значение не названо | 零度以下          | 气温在零度以下。 |
| Минус пять градусов                               | 零下 + число + 度 | 今天零下五度。   |
