# Chinese trainer

The project is an analogue of Anki cards. It was made so that I could learn Chinese; you probably don't need it. The project is almost entirely written by AI.

## Quick start

**Open this address in your browser:** <https://zsxoff.github.io/chinese-trainer.github.io/>

This project is hosted by [GitHub Pages](https://docs.github.com/en/pages).

## Local running

Just run anything HTTP-server. Example for Python `http.server`:

```bash
python -m http.server --bind 127.0.0.1
```
